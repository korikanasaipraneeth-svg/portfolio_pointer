## 5. Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v24.15.0)
- npm 9+

### Installation
```bash
git clone https://github.com/korikanasaipraneeth-svg/portfolio.git
cd portfolio
npm install
```

### Environment Configuration (Optional)
```bash
cp .env.example .env.local
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### Verification & Testing
```bash
# Typecheck
npm run typecheck

# ESLint validation
npm run lint

# Production build
npm run build

# End-to-end browser tests
npm run test:e2e
```

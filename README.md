## 4. Production Security & Hardening Architecture

The application has been audited and hardened according to modern DevSecOps standards:

### HTTP Security Response Headers (`next.config.ts`)
```http
X-DNS-Prefetch-Control: on
Strict-Transport-Security: max-age=63072000; includeSubDomains; preload
X-Frame-Options: DENY
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: camera=(), microphone=(), geolocation=(), browsing-topics=()
```

### Additional Security Implementations
- **Anti-Fingerprinting:** `poweredByHeader: false` completely strips the `X-Powered-By: Next.js` header to prevent automated server reconnaissance.
- **Client Error Boundary (`src/app/error.tsx`):** Noir & Crimson styled runtime boundary capturing fault hashes and offering isolated runtime recovery without page reload crashes.
- **Custom 404 Route (`src/app/not-found.tsx`):** Thematic architectural boundary protecting against dead route exploration.
- **Input Sanitization & Rate Limiting:** All API handlers (`/api/contact`, `/api/telemetry`) validate payload structures and protect against abusive request storms.

- **Response Format:**
  ```json

    "totalVisitors": 42,
    "uniqueCountries": ["India", "United States", "Germany"],
    "recentAccess": [
      {
        "id": "tel-1741328000-xyz",
        "timestamp": "2026-11-07T05:39:12.000Z",
        "maskedIp": "103.112.***.***",
        "country": "India",
        "city": "Visakhapatnam",
        "device": "Desktop",
        "browser": "Chrome",
        "totalDwellSeconds": 145,
        "sectionsViewed": ["hero", "profile", "skills", "projects"]
      }
    ],
    "geoDistribution": { "India": 32, "United States": 7, "Other": 3 },
    "securityStatus": "OPERATIONAL"
  }
  ```

### `POST /api/telemetry`
Client beacon recording dwell time and section exploration.
- **Payload Format:**
  ```json
  {
    "activeSection": "projects",
    "dwellSeconds": 30,
    "referrer": "https://github.com",
    "screenWidth": 1920
  }
  ```

### `POST /api/contact`
Direct encrypted message dispatch to Korikana Sai Praneeth.
- **Payload Format:**
  ```json
  {
    "name": "Jane Doe",
    "email": "jane@example.com",
    "subject": "AI Systems Collaboration",
    "message": "We would like to discuss a systems architect role."
  }
  ```
- **Responses:** `200 OK` (Message dispatched) | `400 Bad Request` (Invalid input) | `429 Too Many Requests` (Rate limit exceeded).
